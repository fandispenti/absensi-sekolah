Pengaturan Database & Sinkronisasi

Pilih metode penyimpanan data absensi sekolah Anda.

Penyimpanan Lokal Browser Aktif

Semua data disimpan di dalam localStorage browser pada komputer ini. Data bersifat offline dan akan hilang jika cache browser dibersihkan.

Terhubung ke Server Sekolah (SQLite)

Aplikasi menyimpan data secara terpusat ke database SQLite di server lokal sekolah. Otomatis sinkron antar guru/perangkat tanpa perlu memasukkan token GitHub.

Integrasi GitHub Cloud

Simpan database di repositori GitHub Anda. Berguna jika Anda meng-host dashboard ini secara gratis di GitHub Pages agar dapat diakses online oleh guru & orang tua.

Token membutuhkan scope repo. Token ini aman dan disimpan langsung di browser Anda.
Contoh: smkn1/absensi-sekolah
Lokasi file penyimpanan data di dalam repositori.

Alat Sinkronisasi Data GitHub

Sinkronisasi data otomatis aktif saat Anda memperbarui data absensi atau siswa terlambat. Anda juga dapat memaksa sinkronisasi manual di bawah ini.

Unduh dari GitHub ke Browser

Menimpa data lokal di browser dengan versi terbaru yang ada di GitHub.

Unggah dari Browser ke GitHub

Mengunggah paksa data lokal di browser untuk menimpa file di GitHub (gunakan jika terjadi konflik).
